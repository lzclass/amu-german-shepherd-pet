# 来源与制作记录

- 角色：阿牧，一只黑棕毛色、琥珀眼睛、立耳、蓝项圈的德牧，贴纸插画风格。
- 制作时间：2026-10-27 至 2026-10-28。
- 图像生成：OpenAI 内置 ImageGen，以同一角色基准图作为身份参照，分别生成动作条及方向条。
- 后处理：移除洋红背景，按完整姿态组提取，共用比例及基线排列，合成 v2 图集，进行一次边缘色溢出清理。
- 最新修改：握手采用低位轻抬爪；等待采用抱爪和轻微歪头；工作嗅探去掉左右急转；检查采用正面浅点头。
- 左移源条经逐帧镜像整理，保留时间顺序。方向条为同一套已通过检查的头部姿态。

`assets/source/` 包含角色基准、九条动作源图、四个方向锚点和两条方向源图。`prompts/initial/` 保留初始生成提示词；`prompts/gentle/` 保留最新四组动作的生成及修正提示词。源图与最终图集之间包含裁切、缩放、镜像和透明背景处理，因此不能直接等宽切割任意源条来复原最终结果。最终交付以 `assets/spritesheet.png` 为准。

## 实际验证

最终图集通过原制作环境中的结构、逐帧、边缘、质量及 Pets 预检。公开的 JSON 记录保留原检查结果，仅把本机绝对路径替换为仓库相对路径。最终 PNG 的 SHA-256 为：

```text

```

结构验证及 Pets 预检没有错误。独立方向盲评中，四个主方向通过；337.5 度的水平分量较弱，单独观察时存在歧义，带标签的连续方向检查后接受。022.5、067.5、225、247.5 的角度间距也有轻微近似。自动连续性检查将 180 度两耳之间的背景间隙标为疑似孔洞，人工检查确认该处是正常外部背景。报告保留这些警告。

GIF 和 MP4 来自最终图集裁切，使用记录的逐帧时长。动画平滑度仍受有限帧数及宿主播放实现影响。生成提示词可供继续创作，无法保证随机图像生成逐像素复现。本仓库未包含在线生成服务或自动导入工具。
