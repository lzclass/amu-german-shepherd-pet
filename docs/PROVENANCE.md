# 来源与制作记录

- 角色：阿牧，一只黑棕毛色、琥珀眼睛、立耳、蓝色青光项圈的德牧，3D 毛绒渲染风格。
- 版本：1.1.0，2026-10-29。
- 图像生成：OpenAI 内置 ImageGen，以当前宠物图集、3D 基准图和已接受姿态作为身份参照，独立生成每条动作。
- 后处理：移除洋红背景，按完整姿态组提取，使用每行共享的比例与锚点配准，保留腾空位移，合成 v2 图集后进行一次边缘清理。
- 自然度修正：击掌使用同一侧前爪并保留半收爪过渡；检查改为小幅正面点头；扑跳降低顶点以保持完整耳朵和一致大小；邀玩修复换爪问题。
- 左移：对已批准的右移动作逐帧镜像，保留时间顺序；角色没有会因镜像改变含义的单侧道具。
- 视线：沿用同一 3D 版已验收的十六个方向，最终像素与更新前图集中的视线帧逐像素一致，保留其原语义及独立盲评记录。

`assets/source/` 包含当前角色基准、九条动作源图和方向源图。`assets/source/original/` 保留当前动作的原始 ImageGen 条带；左移来自右移的确定性派生。`prompts/natural/` 为当前版的生成及修正提示词；`prompts/initial/` 和 `prompts/gentle/` 为早期 2D 版历史记录。

源图与最终图集之间包含裁切、缩放、镜像和透明处理，不能直接等宽切割任意源条复原最终结果。最终交付以 `assets/spritesheet.png` 为准。

GIF 和 MP4 均从最终编码图集裁切，使用记录的逐帧时长，不使用额外插帧或变速。实际观感仍受有限帧数和宿主播放实现影响。报告检查的是源图、编码图集和有序帧，未直接观察桌面宿主的实时播放或客户端刷新。

公开 JSON 报告保留实际检查结果，将本机绝对路径替换为公开路径或制作素材占位路径。未包含账号 ID、短期上传会话、下载签名、应用配置或本地安装回执。安装包中的 PNG 与本机安装的最新图集使用同一校验值。
